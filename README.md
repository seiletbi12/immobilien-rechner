# Immobilien-Rechner

Mobile Web-App (PWA) zur Immobilien-Bewertung, nachgebaut aus einer Excel-Tabelle.

## Funktionen

- **Kaufpreis-Analyse**: Kaufnebenkosten (10 %), Renovierungspauschale (max. 15 %), Summe Kauf, Kaltmiete, Faktor (Summe ÷ Jahresmiete) mit Bewertung (< 12 gut · 13–16 moderat · > 17 teuer) und Bruttorendite
- **Max. Kaufpreis**: aus m² und Miete pro m² der maximal sinnvolle Kaufpreis (Faktor 15) inkl. Nebenkosten und Renovierungsbudget

## Nutzung

Die App läuft unter https://seiletbi12.github.io/immobilien-rechner/

Auf Android: Seite in Chrome öffnen → Menü → „Zum Startbildschirm hinzufügen“. Danach funktioniert sie auch offline.
